  • Circle must be exactly: TVM, Cheyyar, or PDS
  • Available must be: Yes or No (so you can mark leave/exemption right in the sheet)
  • Other column names are flexible — the app auto-detects them

Step 2: Publish the sheet

  1. In your Google Sheet, click File → Share → Publish to web
  2. In the dropdown, select "Comma-separated values (.csv)"
  3. Click Publish → confirm
  4. Copy the URL it gives you (looks like https://docs.google.com/spreadsheets/d/e/.../pub?output=csv)

Step 3: In the app

  1. Paste the URL into the input box
  2. Click 💾 Save (the URL is remembered in your browser forever)
  3. Click 🔄 Sync Now to fetch the staff list
  4. Every month: just update your sheet → click Sync
⚠️ Anyone with the published link can read your sheet. Don't put confidential info in it.

📖 How to publish a Tracker sheet

Why a per-tab link?

You don't want block staff data exposed — just the Tracker. Google Sheets lets you publish only the Tracker tab.

Steps

  1. Open the Google Sheet that has the Tracker tab
  2. Click File → Share → Publish to web
  3. In the dialog, change "Entire Document" to the Tracker tab specifically
  4. Set format to "Comma-separated values (.csv)"
  5. Click Publish → confirm
  6. Copy the URL (looks like https://docs.google.com/spreadsheets/d/e/.../pub?gid=...&single=true&output=csv)
  7. Click Add Tracker in the webapp → paste the URL → save
⚠️ Anyone with the published link can read the Tracker tab. Don't put confidential info in it.
